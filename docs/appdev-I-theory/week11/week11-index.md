<SessionResources :week="11" />

This week answers a key frontend systems question:

> **How does the browser structure content, execute logic, and build reusable UI components?**

So far, you’ve learned how to build backend logic using Flask and manage data.
Now we move to the browser side:

> **How do we structure pages (HTML), add behavior (JavaScript), and scale UI (components)?**

## Topics Covered

* [Markup Languages](11-markup-langs.md) 
  Learn the evolution from **SGML → XML → XHTML → HTML5**, and how modern web pages are structured using flexible, browser-friendly markup languages.

* [JavaScript Features & DevTools](11-javascript-features.md)
  Understand how JavaScript works as a **dynamic, event-driven language**, how it interacts with the browser using the DOM `console`, and how tools like `DevTools` help debug and inspect APIs, and analyze application behavior`Network & application tab`.

* [Web Components & Framework Foundations](11-web-components.md) 
  Explore **Custom Elements, Shadow DOM, and Templates-slots**, and understand how they enable reusable UI. Why are frameworks needed? like Vue/React build on these reusable components.


## By the End of This Week

You will clearly understand:

* How **HTML structures content** and why HTML5 is dominant
* How **JavaScript controls behavior** and interacts with the browser environment
* How the **DOM connects structure and behavior**
* How **Web Components enable reusable UI systems**
* Why modern frameworks (like Vue) are built on these foundational ideas
